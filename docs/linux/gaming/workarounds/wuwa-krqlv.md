# 客户端资源分级引起的无法脱离启动器运行游戏

> [!IMPORTANT]
>
> 内容编写于 2026-09-30，可能有时效性

鸣潮 3.7 版本引入了客户端资源分级，需要在启动时指定当前包体的资源分级，否则会报错 `Use launcher to start game!`

启动游戏时添加参数 `-krqlv=<资源分级>`，其中 `<资源分级>` 填写 `sd`、`hd` 或 `uhd` 即可，填写的资源分级必须是包体已下载的资源分级 (`/path/to/Wuthering Waves Game/Client/Content/{SD,HD,UHD}`)，否则会报错 `Fatal error!` (未参加测试的默认只会下载 `HD` 包，所以参数必须填 `hd`)

> [!TIP]
>
> 当遇到无法脱离启动器启动游戏时，可以尝试先用启动器启动，然后抓抓游戏进程的 `cmdline` (命令行) 和 `environ` (环境变量) 哦
>
> 题外话，据说异环的登录界面是由启动器注入的，所以没法脱离呢（悲）。我不玩，所以我也没细究下去了
